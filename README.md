# Яндекс Практикум — проекты по анализу данных

Портфолио учебных проектов в Jupyter Notebook.

## Проекты

| Проект | Содержание |
| --- | --- |
| Анализ рынка недвижимости Санкт-Петербурга | Предобработка и исследовательский анализ объявлений о продаже квартир, факторы стоимости |
| Изучение закономерностей успешности компьютерных игр | Исследование продаж игр по платформам, жанрам и регионам, статистические гипотезы |
| Определение выгодного тарифа для телеком-компании | Анализ использования мобильной связи и сравнение тарифов, проверка гипотез |
| Предсказание оттока клиентов | Классификация клиентов, подбор моделей и сравнение качества прогнозов |

## Технологии

Python, Jupyter Notebook, pandas, NumPy, Matplotlib, Seaborn, SciPy, scikit-learn и Plotly (в зависимости от проекта).

## Использование

Каждый проект оформлен в формате `.ipynb` и может открываться через GitHub, JupyterLab или Google Colab. Исходные датасеты могут требоваться отдельно; воспроизводимость запуска на новой среде не проверялась.
